## 🔍 ما المشكلة بالضبط؟

### **بكلمات بسيطة:**
عند فتح موديول المقاولين، كانت الشاشة "ترتعش" أو "تهتز" بشكل مزعج.

### **السبب:**
الكود كان يكتب المحتوى على الشاشة مرتين في نفس الوقت، مما يسبب "رعشة" مرئية.

### **الحل:**
تم تعديل الكود ليكتب المحتوى مرة واحدة فقط.
