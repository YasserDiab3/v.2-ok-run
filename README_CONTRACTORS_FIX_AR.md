# ملخص سريع - إصلاحات المقاولين ✅

## 🔴 إصلاح جديد (2026-01-19): ظهور 8 مقاولين فقط من 36

### المشكلة:
- 36 مقاول مسجلين في قائمة المعتمدين
- فقط 8 مقاولين يظهرون في النماذج (المخالفات/العيادة/التدريب)

### السبب الجذري:
1. **`isApprovalActive()`** كانت تقبل فقط `status === 'approved'` (حرفياً)
2. البيانات قد تحتوي على قيم مثل `'معتمد'` أو `'نشط'` أو حتى فارغة
3. **`chooseBetter()`** لم تكن تحافظ على `approvedEntityId` عند دمج السجلات

### الإصلاح:
1. **`isApprovalActive()`** الآن تقبل:
   - `'approved'`
   - `'معتمد'`
   - `'نشط'`
   - `'active'`
   - `''` (فارغ - للتوافق مع البيانات القديمة)

2. **`chooseBetter()`** الآن تحافظ دائماً على `approvedEntityId`

### للتشخيص:
```javascript
// في Console (F12):
Contractors.debugAllContractorsVisibility()
```
